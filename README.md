# vid2md-dashboard

vid2md 대시보드 화면입니다. GitHub Pages로 배포됩니다: https://ghwnd8938-netizen.github.io/vid2md-dashboard/

- 화면 파일만 들어 있습니다. 데이터 처리는 Google Apps Script, 영상 변환은 `vid2md-worker`가 맡습니다.
- `config.js`에 Apps Script 웹앱 주소와 텔레그램 봇 아이디를 넣으면 동작합니다. 둘 다 비밀 값이 아닙니다.
- 원본 코드와 설정 방법: 비공개 저장소 `my-project-1-`의 `dashboard/`, `gas/`, `deploy/GOOGLE.md`.
